## Project Overview
This repository contains the deliverables for the Data Mining Project (2025/2026) based on the Amazing International Airlines Inc. (AIAI) dataset.
The project focuses on customer segmentation to identify distinct loyalty program groups and support personalized services and targeted marketing strategies.

### Delivery 1 | Exploratory Data Analysis
In this part we:
- Performed descriptive analysis and visualizations to identify key patterns and variables for segmentation; <br>
- Evaluated data quality and its impact on clustering reliability; <br>
- Identified initial behavioral signals indicating distinct customer groups; <br>
- Created and justified engineered features to better capture customer behavior. <br


### Final Delivery | Clustering Analysis
In this part our group focused on:
- Preparing and selecting features for segmentation; <br>
- Applying multiple clustering methods across different segmentation perspectives; <br>
- Comparing results and proposing a final integrated segmentation solution. <br>
